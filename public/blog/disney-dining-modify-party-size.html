Friend joined the trip — why you can’t just add them to a hard Disney dining reservation

September 28, 2026

You’re booked for Walt Disney World. You already hold a hard dining reservation — for three, say. Then a friend joins the trip, or the toddler is confirmed, or the split party reunites. You need four.

In My Disney Experience, growing that reservation is not a one-tap edit that keeps the same time. Modify asks you to pick an available time for the new party size. If nothing matches the slot you already had, you can lose that original time while you hunt for the size you actually travel with.

This post is the calm path for that miss — already-held ADR, can’t grow — not a same-day scramble tip, and not affiliated with Disney.

What modify actually does

planDisney’s guidance on changing the number of people on a dining reservation is: open the reservation → Modify → adjust Party Size → Select an Available Time → Book Now (planDisney — change number of people). Disney’s offerings can change; use the live app flow as the source of truth.

Disney Food Blog’s modify walkthrough matches that shape: change party size, then Search / pick an available time — and the search may show no table for the size you need (DFB — easiest ways to modify).

So when the party grows, the app is looking for inventory at the new size. It is not quietly expanding the table you already hold.

What to do first

  1. Keep the original ADR if it is still useful as a bridge (or for whoever still fits it).
  2. Search your true party size and dates yourself on Disney’s site or app — including other meal times the same day.
  3. Book a solid backup you’ll actually enjoy if the hard table never reopens for the larger size.
  4. Day-of: asking at the host stand is a request only. Do not assume a smaller ADR covers a larger walk-in party.

What not to claim

Do not invent Disney policy. Especially: do not publish “book a larger party then shrink later,” or any tip framed as Disney closing a loophole, as official booking rules. If it isn’t in Disney’s own modify flow or a primary Disney answer, leave it out of the public body.

No guarantee of a walk-up or day-of save. Policies and offerings change. When in doubt, use Disney’s site and app.

Calm recovery + soft CTA

  • Keep checking Disney for your true party size and dates.
  • Treat a smaller hold as incomplete if you still need the larger size.
