Magic Table Finder SMS Consent Flow

This public page documents how Magic Table Finder collects opt-in consent for Disney dining reservation SMS alerts.

How Users Opt In

  1. Users visit https://magictablefinder.com/ and sign in to their Magic Table Finder profile.
  2. They create a Disney dining watch by choosing a restaurant, party size, date or dates, meal period, and optional time window.
  3. Before submitting, they must actively check an unchecked SMS consent checkbox.
  4. The watch cannot be created until the checkbox is selected.
  5. After opt-in, Magic Table Finder sends SMS alerts only when matching Disney dining reservation openings are found.

Reviewer Notes

The live watch creation form is profile protected because it controls real reservation alerts for a private family account. This page publicly shows the same consent language and links reviewers need to verify the opt-in workflow.

Program name: Magic Table Finder Disney dining reservation alerts.

Message frequency: varies based on user watch activity and Disney reservation availability.
