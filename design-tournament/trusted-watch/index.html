FAQ

Straight answers

Do you text every open table?
No. We only text when a matching reservation time newly opens. Tables that were already available stay quiet — this is an alert product, not a live availability board.
Whose phone gets the alert?
The signed-in profile's phone. Craig's watches go to Craig's phone. Jessica's watches go to Jessica's phone. There is no shared household inbox.
Is this an official Disney product?
No. Magic Table Finder is an independent tool for Walt Disney World dining watches. We are not affiliated with, endorsed by, or sponsored by The Walt Disney Company.
How often do you check?
Every 10 minutes. You can see when the checker last ran — healthy, needs attention, or stale — right in the header.
When do you ask for SMS consent?
When you create a watch, not at sign-in. You must check an explicit consent box before Create Watch is enabled. You can opt out anytime by replying STOP.
What if nothing opens?
You wait. We keep checking, but we cannot guarantee a table will open. No alert means no new matching opening — not that we stopped watching.
